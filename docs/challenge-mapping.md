# EventPilot AI — Hacktoberfest Challenge Mapping

| Challenge Requirement | EventPilot AI Feature | Implementation & Technical Evidence | Verification Status |
|---|---|---|---|
| **Channel Your Inner Sloth** (Automate tedious work) | 1-Click Complete Event Plan Generation | User enters event parameters once (occasion, guest count, budget, food, atmosphere); backend generates comprehensive plan in seconds. | **VERIFIED** (Tested live & via automated API test) |
| **Personalized Recommendations** | Tailored event themes, catering menus, schedules & checklists | Instruction-tuned Gemma/Qwen structured prompt templates in `backend/planner.py` conditioned on user constraints and cultural touches. | **VERIFIED** (Structured JSON output with Pydantic validation) |
| **Reduce Planning Effort** | LazyTimeline & Automated Checklists | Chronological milestone calculation relative to event date with automated overdue detection (`backend/planner.py`). | **VERIFIED** (`test_date_math_and_overdue_tasks` passed) |
| **Budget-Aware Planning** | BudgetGuard Deterministic Engine | Python/JS deterministic arithmetic for allocations, 7% contingency reserve, real-time edit recalculations, and over-budget alerts. | **VERIFIED** (`test_deterministic_budget_calculation`, `test_over_budget_detection_and_recalculation` passed) |
| **Open-Weight AI (Best Use of Gemma)** | Gemma Model Provider Abstraction | Configurable provider (`backend/ai_service.py`) supporting local Ollama (`gemma2:2b`, `qwen2.5-coder:1.5b`) and OpenAI-compatible hosted Gemma endpoints (e.g. Groq `gemma2-9b-it`). Rejects silent fake fallback on inference error. | **VERIFIED** (`test_generate_live_inference_failure_returns_bad_gateway_no_silent_fallback` passed) |
| **Render Integration (Best Use of Render)** | Turnkey Web Service Blueprint | `render.yaml` with Python 3.11, `$PORT` binding, `/api/health` check endpoint, decoupled hosted inference architecture. | **VERIFIED** (`render.yaml` specification & health check tested) |
| **Sentry Integration (Best Use of Sentry Agent Tracing)** | Connected AI Workflow Telemetry Spans | `sentry-sdk` instrumentation across `event_plan.validate_input`, `event_plan.model_inference`, `event_plan.parse_output`, `event_plan.calculate_budget`, `event_plan.build_timeline`, and `event_plan.persist`. Privacy-safe attributes only. | **VERIFIED** (`test_diagnostics_endpoint`, `test_generate_event_demo_mode_records_span` passed) |
| **Data Integrity & Persistence** | Local SQLite Repository | Parameterized SQL CRUD operations in `backend/database.py` with clean schema separation and transaction safety. | **VERIFIED** (`test_save_and_retrieve_event_lifecycle` passed) |
